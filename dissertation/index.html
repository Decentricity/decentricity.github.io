CAN WE COMPILE A BRAIN?

Translating a fruit fly's biological visual circuit into a radically more efficient artificial neural network — while preserving what that circuit actually does.

A research proposal in cross-architecture functional transplantation, computational neuroscience, and the boundary between biological and machine intelligence. Not a claim that we can already copy a brain: a falsifiable plan to find out which parts of its computation can be carried across architectures.

01 /

The hypothesis

A function learned or implemented by a biologically grounded neural circuit may be reproducible by a smaller, structurally different computational model — one optimized for contemporary hardware, rather than constrained to look like its biological origin.

The question worth answering

Can we preserve a fly's visual computation without preserving its wiring?

Not just matching familiar examples. Matching the original system across new visual stimuli, changes in motion, temporal dynamics, and targeted circuit disruptions — at a measurable reduction in compute.

Important distinction: FlyVis is already a neural-network simulation constrained by biological connectivity. This project is not literally turning a non-neural connectome into the first neural network. The proposed advance is to translate a connectome-constrained dynamical network into a different, more efficient architecture and test how much of its computation survives.

02 /

The experiment

A tractable first investigation targets motion processing in the fruit-fly optic lobe, not the entire animal or anything resembling human consciousness.

Input 01Biological wiring

Use a published, documented visual-circuit connectivity model.

Reference 02Simulate vision

Run FlyVis with moving edges, optic flow, and temporal stimuli.

Translate 03Build a new network

Train or derive compact CNN, recurrent, state-space, or other candidate students.

Challenge 04Probe equivalence

Use held-out stimuli, distribution shifts, and causal perturbations.

Result 05Measure efficiency

Report accuracy, latency, memory, energy proxies, and speedups.

Operational definition

What would count as “the same”?

Define observables before training: motion-direction tuning, optic-flow predictions, response time courses, robustness on novel stimulus families, and downstream control behavior. Establish acceptable error bounds and report where equivalence fails.

The bold version

Give it a virtual body

Replace the visual-processing module in an embodied fly simulation such as FlyGym. Does the translated circuit still help a simulated fly stabilize, navigate, or avoid obstacles?

Controls

Beat the obvious baselines

Compare a direct task-trained network, a conventional compressed/distilled student, and an architecture-matched student. Match training data and compute budgets, and ablate which biological constraints matter.

Strongest possible result

Beyond imitation

Show that a compact student retains interpretable circuit functions under out-of-distribution inputs, temporal perturbations, and targeted simulated lesions. Investigate whether this generalizes across multiple visual subcircuits.

Scientific caveat: Finite tests cannot prove two neural systems “work exactly the same.” A wiring diagram alone does not specify synaptic physiology or neural dynamics. The defensible claim is measured functional equivalence for specified tasks and intervention regimes, with uncertainty and failure cases reported explicitly.

03 /

Why it matters

Neuroscience

Which circuitry is essential?

If a much simpler model retains the same behavior, we can ask which biological details are necessary for function and which may be implementation choices.

Machine learning

Biology as a source compiler

A reproducible method for translating connectome-inspired computation into efficient models could inform novel model design and compression strategies.

Edge computing

Smaller intelligence, closer to the sensor

Visual motion processing is immediately relevant to small robots, drones, and energy- or bandwidth-constrained devices.

Big questions

Does function depend on substrate?

Success would motivate deeper questions about computational identity and what it means to preserve a capability across different physical or virtual substrates — not prove mind uploading or consciousness transfer.

04 /

A realistic first 90 days

Reproduce the foundation

Run FlyVis pretrained models and examples, inspect input/output representations, and establish reference response curves for selected motion stimuli.

Scope a single function

Choose direction selectivity or optic-flow estimation; select a circuit/output set where predictions are defined and testable.

Build two student architectures

Start with a small recurrent network and a convolutional or state-space model; use supervised distillation as a baseline, not as a presumed novel result.

Design tests before celebrating

Hold out novel speeds, orientations, contrasts, temporal patterns, and perturbations; compare functional fidelity to hardware cost.

Write the novelty review

Map nearby work in model distillation, connectome-constrained modeling, mechanistic equivalence, and circuit-level causal testing; revise the thesis claim where literature already covers it.

Initial scope is plausibly accessible without a wet lab using published data, pretrained code, and modest local GPU resources; actual runtime and feasibility still require profiling. A full adult-brain simulation is not the starting milestone.

05 /

Existing science & data

These are published foundations and reusable resources, not results of the proposed dissertation.

2024 / PEER-REVIEWED · NatureLappalainen et al. — Connectome-constrained networks predict neural activity across the fly visual system ↗

Closest foundation. A deep mechanistic network built from connectivity for 64 motion-pathway cell types; task-optimized models reproduce several known motion-processing response properties. Source code, pretrained models and notebooks · Documentation.

2024 / PEER-REVIEWED · NatureDorkenwald et al. — Neuronal wiring diagram of an adult brain ↗

The FlyWire whole-brain connectome of an adult female fruit fly: 139,255 neurons and approximately 54.5 million chemical synapses. Codex data explorer · Download portal · Programmatic tutorials.

2020 / PEER-REVIEWED · eLifeScheffer et al. — A connectome and analysis of the adult Drosophila central brain ↗

The earlier hemibrain dataset provides a large, annotated view of central-brain connectivity. Important for memory/navigation extensions, but it is not the complete visual system. neuPrint · Janelia resource page.

2025 / PEER-REVIEWED · Nature MethodsNeuroMechFly v2 — Simulating embodied sensorimotor control in adult Drosophila ↗

A more ambitious behavioral testbed with vision, body dynamics, and sensorimotor control. FlyGym code.

2026 / PEER-REVIEWED · NatureDistributed control circuits across a brain-and-cord connectome ↗

A newer whole-CNS fly dataset connecting brain to ventral nerve cord, relevant if the project later extends from vision to motor output or embodied control.

Where the research gap might be

Connectome-constrained models, distillation, model compression, and embodied fly simulation already exist. The possible contribution is a rigorously evaluated method for cross-architecture translation that preserves multiple biological functional signatures and causal responses while improving computational efficiency. Novelty has not yet been established; a systematic literature review is essential.

Other dissertation ideas

A small portfolio of adjacent moonshots to revisit with mentors. Each is a research question, not an announced breakthrough.

002 / cross-substrate learning

Can we transplant a memory?

Transfer a learned capability between neural systems with different architectures, then test whether behavior and causal dependence on the learned representation survive. The challenge is defining “memory” beyond ordinary knowledge distillation.

003 / machine consciousness adjacent

A functional fingerprint of identity

Can a set of adversarial behavioral and causal probes distinguish mere output mimicry from a genuinely preserved computational mechanism? Frame it as functional identity, not a test of subjective experience.

004 / sovereign embodied AI

Biological intelligence on the edge

Investigate whether biologically inspired, compact sensorimotor controllers outperform conventional small neural models under strict latency, energy, and autonomy constraints.
