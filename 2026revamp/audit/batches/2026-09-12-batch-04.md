## Human-upload / synthetic-person lineage

### `Decentricity/HumanUploader` — PUBLIC — authored first-class historical experiment
README explicitly describes **Human Uploader 1.0 / Unggah Saya 1.0**, Python programs using OpenAI to generate personality/conversation questions, record a human's answers, and build text corpora intended to approximate that person's mental model in a trained LLM. English and Indonesian variants are documented. It explicitly links three other Decentricity tools as a pipeline: `Train-AllFilesInFolder`, `Dialogos`, and `CorporoSano`.

This is substantive authored transhumanist/AI work and should probably be represented as a historical project/experiment, with the helper repositories beneath it rather than as independent flagship projects.

### `Decentricity/Train-AllFilesInFolder` — PUBLIC — supporting training utility
No README. Single `trainfromhere.py` enumerates non-Python files in its folder, loads them as text via HuggingFace Datasets, tokenizes with `cahya/bert-base-indonesian-1.5G`, and trains a BERT sequence-classification model via HuggingFace Trainer. README evidence from HumanUploader explicitly identifies this script as part of the human-upload training workflow. Normalize as support under HumanUploader/Lina archaeology rather than standalone flagship.

### `Decentricity/CorporoSano` — PUBLIC — authored supporting data-cleaning utility
README describes a bilingual English/Indonesian text sanitizer for code-switched corpora. It removes English-language segments while preserving non-English text/short English phrases, and sanitizes URLs, phone numbers and junk tokens while backing up originals. HumanUploader explicitly links it as preprocessing for bilingual upload corpora. Supporting utility; independently useful but best grouped in this lineage.

### `Decentricity/Lina-LocallyHostedChatbot-Bert` — PUBLIC — historical Lina/Gina experiment
No README; single `linalocalbert` source file. It is a Telegram chatbot using `cahya/bert-base-indonesian-1.5G` / BERT masked-LM generation, gTTS voice output, speech-recognition support and URL scraping/context. The source inconsistently names the persona Lina/Gina, matching the surrounding historical assistant lineage. Authored experiment, not current flagship.

## Voice assistant experiment

### `Decentricity/smarter_alexa` — PUBLIC — authored local voice-agent experiment
No README. Root contains `listen.py`, `talk.py`, and sample `audio.wav`. `talk.py` records a 5-second microphone clip, transcribes locally with Whisper `base`, sends the text to a local Ollama Mistral endpoint, then uses Suno Bark Small to synthesize/play sentence chunks and records a corpus. Concrete authored local voice-agent experiment; likely group with Lina/local-assistant work rather than call it an Alexa product.
