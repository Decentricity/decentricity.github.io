# Audit batch 02 — project-lineage resolution

## Flipside

### `Decentricity/flipside` — PRIVATE — first-class project source
No README. Root inspection shows the web game runtime (`app.js`, `index.html`, `styles.css`, town/minigame files and gameplay data). `index.html` identifies the game as **Flipside.ink — Turn-Based Tactics**, documents tank/wizard/rogue/healer roles, and contains an end-game note: “I made this game in 24 hours based on a dream I had,” linking to `@decentricity`. Evidence supports authored first-class project status.

### `Decentricity/FlipsideAndroid` — PRIVATE — supporting/platform repo
`readme.md` describes a native Android WebView wrapper around the bundled Three.js Flipside tactics game, with turn-based and RTS modes, GunDB multiplayer, overworld/story, persistence, procedural rendering, and the same unit-role system. Normalize under one **Flipside** project, not a separate project. Keep private repository details/URLs off the public graph by default.

## LinaWatchOS

### `Decentricity/LinaWatchOS` — PUBLIC — first-class project/docs
README explicitly says it turns a TicWatch Pro 2018 running AsteroidOS into a terminal-mode watch: Linux remains, Lipstick remains for now, and Lina's voice loop is foreground functionality. README explicitly names Decentricity/Pandu as owner and states that runtime code is in `watch-voice`.

### `Decentricity/watch-voice` — PRIVATE — supporting/runtime repo
README identifies it as the source and installer for Lina on the AsteroidOS TicWatch. It implements the on-watch voice loop, local watch controls, Groq STT/chat calls, Pico TTS, voice/transcribe/text/thinking modes, music control, console/watchface integration, Wi-Fi healing and device-specific audio/display behavior. Normalize both repos under one **LinaWatchOS** project; do not expose the private runtime repo by default.

## Vive Flow AR Writer

### `Decentricity/vive-flow-ar-writer` — PUBLIC — first-class XR project/component
README: horizon-locked writer for HTC Vive Flow, grown from Flow HUD. It keeps the dual-eye passthrough visor and adds a canvas-rendered text box pinned to the artificial horizon, controllable with a Bluetooth keyboard. It explicitly links the Flow HUD lineage. Treat as a distinct application within the broader **Vive Flow resurrection / AR toolkit** project family, not generic XR experimentation.

## Lina Offline Assistant

### `Decentricity/lina-offline-assistant` — PUBLIC — first-class project
README describes a fully local headless companion AI: continuous microphone listening, faster-whisper STT, Ollama chat, Chroma long-term memory, Piper TTS, thinking fillers, and btop-style terminal UI. Core loop requires no cloud APIs. This is sufficiently concrete for first-class project status.

## Chordynaut / Chordysol

### `Decentricity/chordynaut-android` — PUBLIC — Chordynaut Android component
README describes Chordynaut as a mobile-first chord instrument and loop sketchpad with chord grid + strum lane, synth engine, tonic/mode controls, metronome, performance recording, loop recording/overdub and microphone sampling. This repo is a WebView-based Android wrapper around the web instrument.

### `Chordynaut/chordynaut-android` — PUBLIC — current org Android component
Same product lineage, newer release location; includes WAV/JSON export and local runtime packaging.

### `Chordynaut/chordynaut.github.io` — PUBLIC — primary web project/site
README describes the browser chord instrument and its human-first Solana provenance direction. It supports locally signed export bundles containing audio, performance data and a cryptographic receipt without claiming minting/onchain storage.

### `chordysol/chordysol.github.io` — PUBLIC — derivative experiment/branch
README explicitly calls Chordysol a cosmetic fork of Chordynaut prepared for Solana integration. It now supports the same signed-bundle flow. This should be represented as a related Chordynaut experiment/version, not a wholly independent flagship project unless later evidence shows independent evolution.
