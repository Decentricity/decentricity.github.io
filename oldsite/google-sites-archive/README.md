# Original Decentri.city archive

This directory is a preservation snapshot of the old Google Sites version of Decentri.city.

Sources:
- Custom domain: https://www.decentri.city/
- Published Google Sites page: https://sites.google.com/view/decentricity/1
- Google Sites preview/editor reference supplied by the owner: https://sites.google.com/u/0/d/1vMU47SEvD9OYacrx3jUiIUF2unv5awRi/preview
- Drive item title shown by the owner: `www.decentri.city` (modified 2023-04-02)

Notes:
- Google Drive's public API does not expose/export the native Google Sites container through the connected Drive tooling, so the site itself is preserved here by mirroring the published version.
- Drive-hosted files directly linked from the site are separately downloaded in `drive-linked-files/` where publicly exportable.
- External sites such as YouTube, press articles, and unrelated off-site links are not mirrored.
